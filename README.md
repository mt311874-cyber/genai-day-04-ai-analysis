# Day 4 – AI Image Creation with Different Tools

## Overview

Day 4 focused on **AI image creation for aviation and travel-related communication**. The practical activity involved creating professional images using different AI tools and writing suitable prompts for each tool. The main tools explored were **ChatGPT, Canva, Gemini, Microsoft Copilot, and Leonardo.Ai**. The activity helped in understanding how Generative AI can create realistic and attractive visuals for aviation businesses, airports, airlines, training, and passenger-awareness campaigns.

## Practical Activities

### 1. ChatGPT – Airline Advertisement

A promotional image was planned for an airline advertisement. The prompt focused on a modern commercial aircraft flying above soft clouds with a bright blue sky, premium blue and white colours, cinematic lighting, and a sophisticated travel atmosphere. The image was designed to communicate travel, freedom, comfort, and adventure.

### 2. Canva – Airport Social Media Campaign

Canva was used to create an airport social-media campaign concept. The prompt included young and diverse travellers exploring a modern airport terminal, with activities such as check-in, boarding, shopping, and relaxing in the lounge. The objective was to create an energetic and engaging travel visual.
